65 original glossy object icons on a 64×64 viewBox. They're full color and don't take an ink, so they read on Light, Dark and Technozen. Each is lit from the top left, with a rim, a clipped shine, a caustic base and a floor shadow. Use at 32px or larger (48 to 96px is best), freely, inside an Orb at about 66%, in a Tile at 48px, or in an Alert at 32px. The status orbs (check, info, warning, error, help, plus, close, play, pause, sync, download, upload, wifi, wind) carry white glyphs, except close and warning, which carry dark glyphs.
