Twelve original vector wallpapers, 1600×1000, for `background-size: cover` behind glass.

Light theme: clear-sky, meadow, sunrise, ocean, water, bokeh-day, vectorgarden and technozen (the last is for the Technozen theme).

Dark theme: aurora, bokeh-night, dark-ribbons and deep-sea.

They're static and don't change with the theme. Pick the one that matches, or use the Scene component when the backdrop should switch with the theme.
