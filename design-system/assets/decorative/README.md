Transparent overlays to position over a backdrop. Use one or two per screen.

- swoosh-white, swoosh-aurora, swoosh-aqua: light ribbons for Light, Dark and Technozen.
- lens-flare, light-rays: sunlight for Light only.
- sparkles, bubble-cluster, bubble-single: highlights and the signature bubble motif.
- flourish: a Vectorgarden swirl for corners.
- reflection-floor: a glossy shelf to set under a hero object.
- loader: an animated orb spinner as a standalone SVG. In React UI, use the Spinner component.
